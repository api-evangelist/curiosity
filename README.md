Curiosity provides an AI‑powered enterprise knowledge graph platform that lets organizations connect, enrich, and query their data across systems. Built for on‑premises or private‑cloud deployment, Curiosity Studio enables users to build custom AI‑driven tools, search, embeddings, and agents while keeping data within their own infrastructure. The platform supports a REST API, SDKs for C# and Python, and extensive developer documentation covering data ingestion, security, and extensibility.

**Areas:** Artificial Intelligence · Knowledge Graph · Enterprise · Data Integration · On-Premises · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Curiosity: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
